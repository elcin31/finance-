# FINLAB Academy 0.1

Интерактивная финансовая академия на русском языке с финансовым английским. **18 уроков, 3 экзамена, 112 проверяемых упражнений, 72 английских термина и 3 финансовых инструмента.**

**Приложение:** [finance-swart-six.vercel.app](https://finance-swart-six.vercel.app/).
Production размещён в существующем Vercel-проекте `finance`.

Репозиторий: [elcin31/finance-](https://github.com/elcin31/finance-). Существующий Vercel-проект называется **finance**; его метаданные подтверждают связь с этим репозиторием. Другие пользовательские репозитории и базы при разработке не использовались.

## Запуск

Нужен Node.js 24 и npm.

```bash
npm ci
cp .env.example .env.local
npm run dev
```

Откройте `http://localhost:3000`. Без переменных Supabase доступны гостевые функции: onboarding, последовательные уроки и экзамены, лаборатория, библиотека, темы и локальный прогресс. Интерфейс явно сообщает, что синхронизация не настроена.

Для аккаунтов заполните две **публичные** переменные в `.env.local` значениями отдельного FINLAB-проекта. Не используйте `service_role` или secret key. Полная настройка базы, email и Redirect URLs: [docs/supabase.md](docs/supabase.md).

```bash
npm run typecheck
npm test
npm run build
npm run start
npm run test:e2e
```

Playwright использует Chromium из `/usr/bin/chromium`, если он установлен. Иначе один раз выполните `npx playwright install chromium`. Переменная `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` задаёт собственный путь. E2E запускает production-сервер или использует уже запущенный на порту 3000; сначала выполните build. CI проверяет приложение без привилегированных credentials.

## Что работает

- Главная с продолжением урока, фактическим прогрессом, заданием дня, последними темами и очередью повторения.
- Onboarding: 5 целей, уровень, темп и 3 диагностических вопроса. Первый урок каждого модуля открыт без регистрации. Базовые уроки можно повторять.
- Три модуля по 6 уроков и экзамену: основы финансов, финансовая математика, введение в инвестиции.
- Типизированный движок: объяснение, формула, разбор, интерактивная модель, выбор одного/нескольких ответов, число, верно/неверно, сопоставление, сценарий и резюме.
- Проверка обязательной практики, обратная связь, повторные попытки, порог экзамена 70%, сохранение каждого черновика и позиции.
- Калькуляторы сложных процентов, PV/FV и портфельной доходности. Recharts загружается отдельно; данные графиков также доступны в таблицах.
- Поиск по словарю и формулам, ссылки к урокам. Весь финансовый контент оригинальный; рыночные котировки и внешние источники не имитируются.
- Профиль: вычисляемое освоение навыков, точность, история попыток, результаты экзаменов, темп, тема, JSON-экспорт.
- Настоящие Supabase email/password Auth, выход, запрос восстановления и обновление пароля; PostgreSQL с RLS и атомарной синхронизацией. Гостевой импорт дедуплицируется по UUID.
- Светлая/тёмная темы, мобильная навигация, safe areas, клавиатура, обработка ошибок и повреждённых сохранений.
- PWA manifest, собственные PNG-иконки, service worker, офлайн-перезагрузка ранее загруженных публичных страниц.

## Архитектура

```text
src/app/           App Router, metadata, manifest, error/loading states
src/components/    shell, lesson engine, exercises, onboarding, lab, library, profile
src/content/       versioned modules, lesson data, vocabulary, content checks
src/lib/           pure finance/evaluation/progress functions, validation, Supabase adapters
public/            service worker, offline fallback, original icons
supabase/          ordered SQL migrations and two-user RLS regression suite
tests/             guest E2E and optional real-account integration test
```

Стек: Next.js 16.4.3, React 19.3.1, TypeScript strict, Tailwind 4, Supabase JS 2.118, Recharts 3, Lucide, Vitest 5, Playwright 1.64. Версии закреплены в package.json и lockfile.

Модель освоения, точность чисел, версии контента и ограничения хранения: [docs/architecture.md](docs/architecture.md). Реально выполненные проверки: [docs/verification.md](docs/verification.md).

## Vercel

Используйте **существующий** проект `finance`, team `elcin31s-projects`, ID `prj_rdsX7IPKPDqpB3w8ZqBqklBX6kbO`. Не создавайте новый проект при локальном запуске CLI.

1. Убедитесь, что проект связан с `elcin31/finance-`, корневая директория — корень репозитория, Node — 24.x.
2. Настройте `NEXT_PUBLIC_SUPABASE_URL` и `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` для нужных окружений до сборки. В текущем проекте обе публичные переменные настроены для production, preview и development.
3. `vercel.json` задаёт Next.js, `npm ci` и `npm run build`; дополнительный сервер не нужен.
4. В Supabase добавьте фактический опубликованный адрес и `/profile` в Site URL/Redirect URLs. Подключите SMTP для внешних пользователей, проверьте доставку писем.
5. Публикуйте проверенный commit через Git integration либо явно выбранный существующий Vercel-проект. Deployment Protection не отключайте для автоматизации.

PWA требует HTTPS или localhost. На Android установка доступна через меню Chrome, на iOS — Safari → Поделиться → На экран Домой. Офлайн-кэш не содержит ответов Auth API или данных аккаунта. Вход и подтверждённая синхронизация требуют сети. Несинхронизированные ответы сохраняются отдельно для конкретного аккаунта и повторно отправляются при следующем входе/восстановлении сети; успешность отмечается только после ответа БД.

## Границы 0.1 и следующий релиз

Доставка регистрационных писем и password recovery зависит от SMTP, адресов перенаправления и лимитов Supabase. Браузерная проверка входа проводится на отдельном подтверждённом тестовом аккаунте и не доказывает доставку писем. Физическая установка на Android/iOS требует отдельной проверки на устройствах; Chromium проверяет manifest, service worker и офлайн-сценарий.

Результаты предназначены для обучения; клиентский экзамен не является защищённым профессиональным сертификатом. Лимит одного документа прогресса — 2 МБ / 20 000 попыток / 128 состояний; перед масштабированием истории её следует нормализовать/архивировать. Одновременные изменения одного черновика разрешаются по времени изменения, а попытки объединяются без потерь. Общее редактирование одного аккаунта в нескольких вкладках в реальном времени в 0.1 не реализовано.

FINLAB 0.2: финансовая отчётность и экономика рынков, интервальное повторение, новые кейсы и независимая предметная редактура, нормализованная аналитика/архив истории, проверка на физических iOS/Android и улучшение доступности. Career Mode, Company Analysis Lab и Portfolio Simulator следует добавлять полноценными рабочими разделами.
