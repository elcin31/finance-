# FINLAB Academy 0.2

Интерактивная финансовая академия на русском языке с профессиональным финансовым английским. Обновление существующего FINLAB 0.1: история уроков и зачёты сохраняются.

**Приложение:** [finance-swart-six.vercel.app](https://finance-swart-six.vercel.app/). **Репозиторий:** [elcin31/finance-](https://github.com/elcin31/finance-). Используется существующий Vercel-проект `finance` и отдельный Supabase `finlab-academy`; другие проекты не изменяются.

## Содержание

- **18 уроков** в трёх модулях; **89 упражнений** внутри обычных уроков.
- **60 новых финансовых заданий** и **40 заданий Financial English**: термины, чтение аналитики, расчёты и профессиональные формулировки.
- **14 генеративных финансовых шаблонов**, три уровня сложности, воспроизводимый seed и пошаговый разбор.
- **3 серверных экзамена**: по 8 вопросов, по 16 вариантов на модуль; 384 вопроса-варианта в активном банке. Проходной балл — 80%.
- **20 компетенций**, 72 термина в библиотеке и 20 контекстных карточек профессионального английского.
- **3 калькулятора** и **5 интерактивных моделей**: проценты, инфляция, дисконтирование, риск, диверсификация.

23 прежних клиентских экзаменационных упражнения остаются в версионированном контенте для совместимости истории 0.1. В текущем интерфейсе их заменяет серверная проверка; они не добавляются к числу новых заданий. Варианты генератора не выдаются за отдельные авторские уроки. Все финансовые данные — явно учебные условия.

## Локальный запуск

Node.js 24 и npm:

```sh
npm ci
cp .env.example .env.local
npm run dev
```

Откройте `http://localhost:3000`. Без Supabase доступны публичные уроки, адаптивная практика, Financial English, библиотека, лаборатория и локальный прогресс. Для **защищённых экзаменов, настоящего входа и синхронизации** нужны две публичные переменные отдельного FINLAB-проекта и применённые миграции. Успешное подключение не имитируется.

```dotenv
NEXT_PUBLIC_SUPABASE_URL=https://YOUR_FINLAB_PROJECT.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=YOUR_PUBLIC_PUBLISHABLE_KEY
```

`service_role`, `sb_secret_*` и пароль базы приложению не нужны. Настройка Auth и базы: [docs/supabase.md](docs/supabase.md), [данные и защищённые экзамены 0.2](docs/data-0.2.md).

## Что работает

- Главная: продолжение урока, текущий модуль, фактический прогресс, персональная рекомендация с причиной, слабые навыки, повторения, последний экзамен и статистика практики.
- Onboarding с целями, темпом и настоящей диагностикой. Публичное знакомство без обязательной регистрации.
- Путь с интерактивной картой 20 компетенций и отдельной вкладкой всех уроков и экзаменов. Предпосылки объясняют следующий шаг, сохраняя доступ к базовому материалу.
- Пошаговые уроки с обязательной практикой, формулами, объяснениями, автосохранением позиции и ответов. Типы заданий: одиночный/множественный выбор, число, сопоставление, порядок, верно/неверно, сценарий, изменяемая расчётная модель.
- Детерминированная адаптация: первые самостоятельные ответы, ошибки, сложность, разнообразие задач, отложенные повторения и результаты экзаменов. Повторное нажатие не начисляет дополнительные знания.
- Интервальное повторение 1 / 3 / 7 / 14 / 30 дней; знакомое фиксированное условие может снова подтвердить удержание после перерыва не менее 7 дней. Реальные задачи и история вместо отметки «я повторил».
- Экзамен с возвратом к вопросам, черновиком между устройствами, серверным оцениванием, отложенным раскрытием решений, слабых навыков и новым вариантом при пересдаче.
- «Мои знания»: компоненты mastery, динамика реальных ответов, сильные/слабые стороны, экзамены, история повторений и достижения на основании результатов. У нового пользователя нет вымышленных графиков.
- Финансовый английский в четырёх направлениях, тематические примеры и ссылки к урокам; поиск формул и терминов в библиотеке.
- Настоящие email/password Auth, выход, запрос восстановления пароля и смена пароля. Гостевые события переносятся по неизменным UUID; экзамены — через серверную проверку гостевого доступа.
- Светлая/тёмная темы, мобильная навигация, клавиатура, safe areas, PWA и офлайн-доступ к ранее загруженному публичному контенту. Графики загружаются отдельно и имеют таблицы.

## Проверка

```sh
npm run typecheck
npm test
npm run build
npm run test:e2e
```

E2E запускает production-сервер; сначала нужна сборка с публичными FINLAB-переменными. Для Chromium: `npx playwright install chromium`, либо установленный `/usr/bin/chromium`, либо `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`. Можно задать `BASE_URL` для проверки существующего deployment.

Для авторизованных сценариев подготовьте **отдельный подтверждённый тестовый аккаунт** и игнорируемый `.env.e2e.local` с `FINLAB_TEST_EMAIL` и `FINLAB_TEST_PASSWORD`, затем `npm run test:auth`. Ничьи реальные пароли в Git не добавляются. API и успешные результаты в тестах не подменяются. Трассы авторизованных браузеров отключены.

SQL-проверки `supabase/tests/security.sql` и `security-v2.sql` выполняются только в изолированной FINLAB-базе; фикстуры откатываются транзакцией. Результаты, найденные ошибки и границы проверки: [docs/verification-0.2.md](docs/verification-0.2.md). Исходный E2E-набор 0.1 сохранён побайтово в `tests/legacy`.

CI использует только публичную конфигурацию FINLAB; её можно переопределить GitHub repository variables `NEXT_PUBLIC_SUPABASE_URL` и `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`. Publishable key уже поставляется браузеру и защищается RLS. Привилегированных ключей и паролей тестовых пользователей в workflow нет.

## Архитектура

```text
src/app/           маршруты App Router, metadata, manifest
src/components/    UI, учебные сессии, экзамены, Auth и синхронизация
src/content/       исходные уроки, новые задания, английский и определения навыков
src/lib/knowledge/ пересчитываемая модель освоения, повторений и рекомендаций
src/lib/           финансовая математика, проверка, seed-генератор, типы и адаптеры
supabase/          аддитивные миграции, закрытый экзаменационный банк, RLS-тесты

public/            PWA, иконки и офлайн-страница
```

Используйте только существующий Vercel-проект **finance**, team `elcin31s-projects`, ID `prj_rdsX7IPKPDqpB3w8ZqBqklBX6kbO`, связанный с `elcin31/finance-`.

2. Проверьте обе публичные переменные для production до сборки, Node 24 и корень репозитория. Они уже настроены для существующего FINLAB-проекта.

## Границы и FINLAB 0.3

- Подтверждение email и восстановление зависят от SMTP, разрешённых redirect URL и лимитов Supabase; вход подтверждённым тестовым аккаунтом не доказывает доставку писем.
- Физическая установка и поведение Safari/iOS требуют проверки на реальных устройствах; автоматизированные сценарии выполняются в Chromium.
- Начало/отправка экзамена и подтверждённая синхронизация требуют сети. Черновики и очередь изменений сохраняются локально; Auth API и личные ответы не попадают в PWA Cache API.
- Личные результаты практики предназначены для самостоятельного обучения. Сервер защищает оценку экзамена от подмены клиентского балла; защищённый браузер или профессиональная сертификация не заявляются. Задачи и формулы находятся в открытом репозитории.
- Объём загрузки истории ограничен валидатором клиента: до 20 000 событий, 256 черновиков и 2 000 экзаменов, не более 3,5 МБ. Пагинация и архивирование нужны до расширения на многолетнее использование. Одновременное редактирование одного черновика разрешается по времени; совместное редактирование в реальном времени не реализовано.
- Supabase advisor сообщает, что проверка паролей по базе утечек отключена. RLS-проверки проходят; настройка этой дополнительной функции и её тарифная доступность проверяются в Dashboard.

Следующий релиз: независимая предметная редактура и исследования обучения, пагинация истории, реальные мобильные устройства и аудит доступности, расширение банка отложенной практики, затем финансовая отчётность и первые Junior Analyst Missions.
