# FINLAB 0.1 — сохранённая архитектура

Этот документ описывает исходный релиз. В 0.2 правила mastery и экзаменов заменены: актуальные алгоритмы — в [knowledge-engine.md](knowledge-engine.md), хранение и серверная проверка — в [data-0.2.md](data-0.2.md). Исторический порог 70% применяется только к зачётам 0.1.

## Учебный контент

`Lesson`/`LessonBlock`/`Exercise` — discriminated unions в `src/lib/types.ts`. Данные трёх модулей отделены от отображения. У каждого урока и задания стабильный ID; урок имеет `version`. Для существенного изменения задачи повышайте версию урока. Попытки и текущий run сохраняют `contentVersion`; legacy-данные без поля относятся к версии 1. При открытии новой версии движок создаёт новый run, старые результаты остаются историей, а в текущий прогресс и mastery не входят.

В уроке нельзя перейти за первое нерешённое обязательное упражнение. Ошибка формата не создаёт попытку. Проверенный неверный ответ сохраняется и показывает принцип решения; после верного ответа открывается полный разбор. Черновик сохраняется на каждое изменение до навигации. Позиция хранится отдельно для каждого урока.

Завершение возможно только после верных ответов на все задания текущего run. Идентификатор run предотвращает повторное завершение. Балл — доля заданий, на которые первая валидная попытка была правильной. Исправления полезны для обучения, но не повышают балл той же попытки экзамена. Экзамен засчитывается от 70%; иначе доступно новое прохождение. Уроки открываются последовательно внутри модуля; первый урок каждого модуля открыт, экзамен требует все 6 уроков. Диагностика рекомендует первый урок модуля и не закрывает базовые темы.

## Освоение навыков

Для каждого упражнения компетенции берётся первый валидный ответ из последнего run, в котором на это упражнение отвечали, только для актуальной версии контента. Вес обычного задания — 1, экзамена — 2. Неотвеченные задания не дают положительного результата.

`mastery = 100 × сумма весов верных первых ответов / сумма весов всех заданий компетенции`.

`accuracy = 100 × сумма весов верных первых ответов / сумма весов проверенных заданий компетенции`.

Покрытие и точность показываются отдельно. Чтение блоков, диагностика и ежедневная мини-задача не добавляют mastery. Финансовый английский оценивается заданиями на терминологию в уроках. Очередь повторения содержит темы с ошибкой в первом ответе последнего run; правильный ответ в новом прохождении снимает тему. Для Financial Statements нет процента до появления соответствующего контента.

## Финансовые расчёты и формат

Чистые функции в `src/lib/finance.ts` независимы от React. Ставки/веса в domain API — доли: `0.075 = 7,5%`. В упражнении с unit `percent` ожидается число процентных пунктов: `7,5` или `7.5%`; `0,075` будет другим ответом. В unit `bps` 25 означает 25 bp; денежные ответы — рубли. Проценты, bp и валюты не преобразуются неявно.

Сравнение чисел: `|actual − expected| ≤ max(absTolerance, |expected| × relTolerance)` с добавкой машинного epsilon. Разрешены точка/запятая и пробелы тысяч; выражения, NaN, Infinity, чужая единица и неоднозначные разделители отклоняются. Для контента допуск обычно 0,01, если задача не задаёт другой. Формат — `Intl.NumberFormat('ru-RU')`.

Капитализация: номинальная годовая ставка `r`, частота `m`, эквивалентная месячная ставка `q = (1+r/m)^(m/12) − 1`. Взносы поступают в конце месяца. Это явная учебная модель между датами капитализации, а не банковский договор. Срок должен выражаться целым числом месяцев. Нулевая ставка имеет отдельную ветку. Расходы и инфляция не включены в эту модель.

PV/FV используют эффективную годовую ставку и согласованный горизонт. NPV включает поток t=0. IRR численно ищется только для обычного потока: первый отрицательный, остальные неотрицательные, хотя бы один положительный. Неоднозначные потоки отклоняются. Доходность портфеля требует неотрицательные веса суммой 100%, одинаковые периоды и отсутствие внешних потоков; нормализация выполняется только отдельным действием пользователя. Доходности не являются прогнозами.

## Данные и безопасность

Гость: версионированный `finlab.guest.v1` в localStorage. Аккаунт: `finlab.progress_documents` с RLS; канонический документ возвращает RPC. Клиент хранит отдельную копию `finlab.account.v1.<uid>` для черновиков/неподтверждённых изменений. При входе сервер объединяется с ещё не отправленными изменениями и однократно с гостевыми UUID. После успешного импорта гостевой ключ удаляется. Выход возвращает новый гостевой контекст; чужой account cache не импортируется.

Синхронизация атомарно блокирует одну пользовательскую запись, дедуплицирует immutable события, выбирает свежие черновики/настройки по реальному времени ISO timestamp. Источник подтверждённого состояния — ответ БД. Если пользователь отвечает во время запроса, новый ответ объединяется с результатом и отправляется следующим запросом. Ошибка показывает состояние «не синхронизировано» и оставляет локальную копию. Историю можно экспортировать в JSON из профиля.

Вход, подтверждение email и восстановление используют настоящий Supabase Auth. Секретные ключи не нужны. RLS и SECURITY INVOKER RPC связывают запрос только с `auth.uid()`. Валидация документов выполняется и в клиентском адаптере, и в PostgreSQL. SQL-прогресс отражает личное обучение: защита от подмены собственной оценки для сертификации не заявляется.

## PWA и производительность

Service worker кэширует только same-origin публичные HTML и статические ресурсы Next.js/иконки. После загрузки маршрута сохраняется его публичный HTML для последующего reload без сети. Auth API, cross-origin запросы, `/profile` и RPC не кэшируются. Для незагруженного маршрута есть offline fallback со списком сохранённых страниц. Клиентские переходы Next.js при недоступной сети могут перейти к полной загрузке документа; гарантируется проверенный reload ранее посещённого урока, а не предварительная загрузка всей программы.

Контент статически типизирован, страницы уроков генерируются при build. Графики Recharts загружаются через dynamic import только на маршрутах/шагах с моделями. Используются системные шрифты и собственная SVG-графика без внешних запросов. Reduced motion отключает анимации. Полные диаграммы доступны в табличном виде.
